## Hakkımda

Bartın Üniversitesi Bilgisayar Mühendisliği öğrencisiyim. Web güvenliği, backend sistemleri, CTF çalışmaları ve LLM destekli uygulamalarla ilgileniyorum.

Temel odak noktam; modern web uygulamalarının nasıl geliştirildiğini, hangi noktalarda güvenlik zafiyetleri oluşabildiğini ve bu sistemlerin nasıl daha güvenli hale getirilebileceğini anlamak. Bu doğrultuda backend projeleri, güvenlik odaklı araçlar, CTF laboratuvarları ve pratik yazılım projeleri geliştiriyorum.

Ayrıca private repolarımda Retrieval-Augmented Generation, LLM tabanlı sistemler ve eğitim amaçlı CTF challenge geliştirme üzerine çalışmalar yapıyorum.

Takım çalışmasına, açık iletişime, analitik düşünmeye ve pratik problem çözmeye önem veriyorum. Özellikle güvenlik odaklı yazılım projelerinde iş birliği içinde çalışmayı önemsiyorum.

## Öne Çıkan Projeler

### ProjectOfDork

Go, PostgreSQL, Docker, Kubernetes, Jenkins ve Google Cloud teknolojileriyle geliştirilmiş cloud-native bir Google Dork sorgu üretici uygulaması.

Uygulama; kullanıcıdan hedef domain alarak Google Dork sorguları üretir, HTTP/HTTPS erişilebilirliğini kontrol eder ve sorgu geçmişini PostgreSQL üzerinde saklar. Projede container tabanlı deployment, Kubernetes manifestleri, kalıcı depolama yapılandırması, NetworkPolicy kullanımı, HorizontalPodAutoscaler ve CI/CD pipeline entegrasyonu bulunmaktadır.

**Teknolojiler:** Go, HTML, PostgreSQL, Docker, Kubernetes, Jenkins, Google Kubernetes Engine, Google Artifact Registry

[Repository](https://github.com/memreok/ProjectOfDork)

---

### GoLang TODO APP

Go backend, frontend arayüzü, PostgreSQL veritabanı ve Docker Compose tabanlı geliştirme ortamı ile hazırlanmış full-stack bir TODO uygulaması.

Bu proje; REST API geliştirme, container tabanlı servis yönetimi, veritabanı entegrasyonu ve basit frontend-backend iletişimini göstermektedir.

**Teknolojiler:** Go, JavaScript, HTML, CSS, PostgreSQL, Docker Compose

[Repository](https://github.com/memreok/GoLang-TODO-APP)

### WebScrapper-Go

HTTP istekleri, web içeriklerinin ayrıştırılması ve Go ile otomasyon odaklı işlemleri denemek amacıyla geliştirilmiş Go tabanlı bir web scraping projesi.

**Teknolojiler:** Go

[Repository](https://github.com/memreok/WebScrapper-Go)

## Diğer Projeler

### VulnTrack

Yazılım geliştirme ve güvenlik ekipleri için hazırlanmış bir zafiyet takip sistemi simülatörü.

Proje; zafiyet kayıtları, önem seviyeleri, durum takibi, kullanıcı atamaları, yorumlar ve aktivite logları gibi süreçleri yönetmeye odaklanır.

**Teknolojiler:** PHP, Laravel, MySQL

[Repository](https://github.com/memreok/VulnTrack)

---

### The Password Game

Kural tabanlı parola oluşturma mantığından esinlenerek hazırlanmış web tabanlı bir parola farkındalık oyunu.

Projenin amacı, kullanıcıların güçlü ve karmaşık parola oluşturma kavramlarını etkileşimli bir senaryo üzerinden anlamasını sağlamaktır.

**Teknolojiler:** PHP, MySQL, HTML, CSS

[Repository](https://github.com/memreok/ThePasswordGame)

## CTF ve Güvenlik Çalışmaları

Aktif olarak CTF yarışmalarına katılıyor ve web güvenliği alanında SQL injection, XXE, kimlik doğrulama problemleri, dosya yükleme zafiyetleri, redirect tabanlı zafiyetler ve yaygın web uygulama yapılandırma hataları üzerine çalışıyorum.

Ayrıca zafiyet tasarımını, sömürü akışını ve güvenli kodlama pratiklerini daha iyi anlamak için eğitim amaçlı CTF challenge’ları geliştiriyorum.
